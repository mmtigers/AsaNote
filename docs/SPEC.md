# よるノート 仕様書(たたき台 / 方向性検討)

子どもの帰宅から就寝までの夜のようすを、**寝かしつけ後に1画面でサッと**記録する家族向けPWA。
[あさノート](https://github.com/mmtigers/asanote) の姉妹アプリとして、同じ技術スタック・UIの作法で作る。

> 状態: 方向性の合意済みドラフト。実装前。決定事項は §10。

## 1. 目的と優先順位

| 優先 | 目的 | 設計への反映 |
|---|---|---|
| 1 | これまで面倒で記録していなかった情報を、寝る前に簡単に残せるようにする | 1画面・タップ中心・既定値あり・全項目任意(総合のみ必須)。「ざっくり」で済ませられること |
| 2 | 親が傾向を振り返る(何が荒れのきっかけか、何が効いたか) | 集計・タイムライン・「試したこと→結果」ログ |
| 3 | 学校・医療に状況を伝える | 期間指定の印刷/PDF・CSVエクスポート(あさノートを流用) |
| 4 | 親子のルール作りの材料にする | 検討事項ボード、効いた対応の可視化 |

**最重要の設計原則は「書く手間を減らす」こと。** 迷ったら項目を増やさず、入力を減らす側に倒す。

## 2. 対象ユーザー・利用場面

- 主な利用者: 子ども(複数可)を持つ保護者。夫婦で1グループを共有。
- 主な利用場面: 子どもが寝た後の数分。夜の最中は入力しない(例外: §4.5 クイック記録)。
- 利用形態: スマホのホーム画面に追加したPWA。オフラインでも記録できる。

## 3. 記録モデル

**1日 × 1人の子ども = 1件の記録。** 兄弟姉妹は子どもごとに記録する(§6)。

### 3.1 項目

| ブロック | 項目 | 入力 | 必須 |
|---|---|---|---|
| 総合 | 今夜の様子: 😌穏やか / 😣少し荒れた / 🌩大荒れ | 3択 | **必須** |
| 節目の時刻 | 帰宅・宿題開始・宿題終了・夕食・お風呂・準備完了・消灯 | 「いま」ボタン or 時刻ピッカー。未入力可 | 任意 |
| 宿題 | 全部 / 一部 / なし(宿題の無い日) | 3択 | 任意 |
| 決め事の達成 | 食洗機・準備など、家庭ごとの期限に間に合ったか | ○/×(項目は設定で増減) | 任意 |
| 自由時間 | TV / YouTube / 動画 / ゲーム / 外遊び / 友達 など | タグ(複数、「＋追加」可) | 任意 |
| 友達・予定 | 約束の有無、相手、場所、時間を守れたか | タグ+短文 | 任意 |
| 夕食 | 食べた / 少し / 食べず + 理由タグ | 選択 | 任意 |
| 荒れ | きっかけ・行動(号泣/物を投げる/暴言/家出/自傷他害を示す言動 等) | タグ(複数)。安全面のタグは別枠で強調 | 任意 |
| からだ | 蕁麻疹・眠気・疲れ・腹痛 など | タグ | 任意 |
| 親の対応 | 時間宣言 / 放置 / 取り上げ / 一緒に遊ぶ 等 + 効いたか(○△×) | タグ | 任意 |
| よかったこと | 短文またはタグ | 任意 | 任意 |
| 明日の予定 | 短文 | 任意 | 任意 |
| メモ | 自由記述(最大2000文字) | 任意 | 任意 |

- タグは初期セット(`src/constants/choices.ts` に集約)+ユーザー追加。よく使うものが上に並ぶ(あさノートの `reasonOptions` と同じ方式)。
- 「大荒れ」「少し荒れた」を選んだときだけ「荒れ」ブロックを展開する(穏やかな日は入力を増やさない)。

### 3.2 手間を減らす工夫(優先度1)

1. **前日の既定値**: 決め事・自由時間タグなど、前日の選択を薄く提示し、1タップで引き継げる。
2. **時刻は「いま」ボタン**: 寝る前に思い出して入れるため、ピッカーは30分前後にスナップ。区分(帰宅:15時台 など)での入力も可。
3. **1画面完結 + 下書き自動保存**: あさノート同様、途中離脱しても復元。
4. **日記文の自動生成プレビュー**: 選んだ内容から文章を作る(あさノートの `recordPreview` 方式)。メモを書かなくても記録として残る。
5. **夜のリマインド**: 未入力の日の21時ごろにPush(時刻は設定可)。

### 3.3 安全面の扱い

- 「死にたい」等の発言、刃物を向ける行為などは**専用タグ**として記録でき、エクスポートでも見落とされない形で出す。
- アプリは評価・診断をしない。相談を促す案内文なども出さない(決定済み)。

## 4. 画面

| ルート | 画面 | 内容 |
|---|---|---|
| `/` | ホーム(記録) | 月カレンダー、子ども切替、記録ボタン。フォームは同一ルート内(あさノート方式) |
| `/timeline` | これまで | 記録の一覧(子ども・様子で絞り込み) |
| `/stats` | 傾向 | §5 |
| `/rules` | 試したこと | 「試したルール→結果」ログと検討事項ボード(§4.4, 第2段階) |
| `/export` | エクスポート | 期間・子ども指定の印刷/PDF・CSV |
| `/group` | 共有 | 子ども・グループ・通知の設定 |
| `/login`, `/updates` | ログイン、更新履歴 | あさノートと同様 |

下部ナビ: 記録する / これまで / 傾向 / 共有(+第2段階で「試したこと」)。

### 4.4 試したこと・検討事項ボード(第2段階)

- 試したこと: 「食洗機は18:45まで」「宿題は30分で」のような**ルール変更**を開始日付きで登録。前後の傾向(荒れ度・消灯時刻)を並べて見られる。
- 検討事項: 「困ったこと」を溜めて、解決したらチェックする簡単なボード。

### 4.5 クイック記録(第2段階)

夜の最中に「荒れた」をワンタップで時刻付きで残し、あとで詳細を足す。

## 5. 傾向(集計)

- 様子の内訳、カレンダー表示(あさノート流用)。
- 宿題開始時刻 × 様子 / 消灯時刻。
- 友達との約束の有無 × 様子。
- きっかけタグの集計、効いた対応の集計。
- 消灯時刻の推移。
- **あさノート連携(第2段階)**: 就寝時刻 → 翌朝の起床・行き渋り。§7 の共有方式を選んだ場合のみ。

## 6. 複数の子ども

- 子どもは `children` として登録(人数制限なし)。記録は必ず特定の子に紐づく。
- ホーム・タイムライン・傾向に子ども切替(あさノートの `ChildSwitcher` 流用)。
- 兄弟が同じ出来事に関わる日(例: 同じ夕食、同じ就寝)のために、**他の子へ共通項目をコピー**するボタンを置く(夕食時刻・消灯時刻など、コピー対象は選択式)。
- 子ども名はハードコードしない。

## 7. グループ共有とあさノートとの関係

要件: **最初は共有でも、後から完全に分けられる**こと。

方針:

1. データ層は `src/lib/db/` に閉じ込め、`groups` / `children` の参照を1か所(`lib/db/children.ts` など)に集約する。
2. よるノートのテーブルは**独立**させる(`evening_records` ほか)。あさノートの `records` と外部キーで結ばない。連携が要る箇所は `group_id` と `child_id` による**論理結合**にとどめる。
3. Supabase の接続先は環境変数のみで切り替え可能にする。
   - **共有モード**: あさノートと同じ Supabase プロジェクト。同じログイン・グループ・子どもを使い、朝夜を横断して見られる。
   - **分離モード**: 別プロジェクト。`groups` / `children` / 認証もよるノート側に持つ。
4. `groups` / `children` 系のスキーマとRLSは、あさノートと**同じ定義を持つ**(共有モードでは重複作成しない、分離モードではそのまま作る)ため、`schema.sql` を「共通部」と「よるノート固有部」に分けて管理する。

**決定: 初期設定は共有モード。** 共通表(`groups` / `group_members` / `group_invites` / `children` と認証)はあさノート側の `schema.sql` を正とし、よるノートは**自分の表だけ**を作る・変更する。
2つのリポジトリが同じDBへスキーマを自動適用するため、互いの表を消さないよう次を守る。

- よるノートの `schema.sql` / 自動適用は、よるノート固有の表・関数・ビューだけを対象にする(`DROP` を共通表に向けない)。
- 表名は衝突しないよう `evening_` を接頭辞にする。
- 共通表の変更が必要な場合は、あさノート側で行ってからよるノートが追随する。
- 分離モードに切り替える場合は、共通部のSQLをよるノート側へコピーして適用する。

## 8. 技術スタック

あさノートと同一。

- Next.js (App Router, TypeScript, Tailwind CSS)
- Supabase (Postgres / Auth / RLS)
- Dexie.js — オフライン優先のローカルキャッシュと同期
- 手書き Service Worker(PWAシェル、Push受信)
- Supabase Edge Functions + pg_cron — リマインドPush
- Vitest / Testing Library / Playwright

**あさノートから流用するもの**: 認証、グループ/招待、子ども切替、月カレンダー、下書き保存、オフライン同期、エクスポート、リマインド、更新履歴とCIチェック。
**新規に作るもの**: 夜のフォーム(時刻入力中心)、タグ体系、集計ロジック、試したこと/検討事項(第2段階)。
